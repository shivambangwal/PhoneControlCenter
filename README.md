# Phone Control Center

The project is split into two independent folders:

- [`local/`](local/) contains the macOS desktop app. Double-click `local/Run Phone Control Center.command` or follow [local/README.md](local/README.md).
- [`webapp/`](webapp/) contains the Hostinger dashboard, bridge scripts, and deployment ZIPs. Upload `webapp/Phone-Control-Center-Hostinger-Upload.zip` to Hostinger; run the bridge from this computer using [webapp/README.md](webapp/README.md).

Historical backups and local bridge credentials are kept out of this repository.
